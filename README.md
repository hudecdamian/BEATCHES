# BEATCHES – After Sunset 🌅

E-commerce landing page pro lifestylovou značku BEATCHES (Kolekce 001). Projekt je postaven na čistém frontendovém stacku s důrazem na atmosféru, prémiovou typografii a plynulý uživatelský zážitek.

## 🛠 Technologie

*   **HTML5** – Sémantická struktura
*   **CSS3** – CSS Grid & Flexbox, plná responzivita, práce s CSS proměnnými pro správu barevné palety
*   **Vanilla JavaScript** – Dynamické renderování produktů, filtrování, logika nákupního košíku a plynulé scroll animace (Intersection Observer)
*   **Zero Dependencies** – Žádné externí knihovny, frameworky ani buildovací nástroje. 

## ✨ Klíčové funkce

*   **Dynamický katalog:** Produkty se generují přes JS. Místo statických fotek jsou použity vektorové (SVG) tvary oblečení, které interaktivně mění barvu podle výběru uživatele.
*   **Kategorizace:** Okamžité filtrování produktů (Vše, Trička a mikiny, Doplňky, Kraťasy).
*   **Interaktivní košík:** Vysouvací postranní panel (drawer) pro přidávání položek, výpočet celkové ceny a odebírání produktů.
*   **Scroll animace:** Prvky se plynule odhalují při scrollování stránky dolů.
*   **Responzivita:** Layout plynule přechází z desktopové mřížky až po optimalizované zobrazení na mobilních telefonech.
